# Changelog

## [Unreleased]

### Added
- Over-the-air updates: once installed, the app picks up new versions on its own the next time it opens; no reinstall needed.
- Workouts: tick each set, a rest timer between sets (with +15 seconds and skip), "tick all", and finish with only part of a workout done. The fitness list shows sets done so far.
- Prayers: বিতর and nafl prayers (তাহাজ্জুদ, ইশরাক, চাশত, আওয়াবীন), and a count of days in a row with all five fard prayers.
- Books: type the exact page you're on; deleting a book asks first.
- Prayer tracker: tick the five daily prayers, see the last seven days, and fill in a day you forgot.
- Fitness guide: walking, home, gym and stretching routines with sets, reps and form tips; mark a routine done today.
- Book reading tracker: add a book with its page count and move your page forward or back.
- Today's tasks: a short to-do list with done items set aside.
- App icon, splash screen and the name "Amala Lifestyle".
- Backups now include prayers, workouts, books and tasks; older backup files still import.

### Changed
- Smaller, calmer type, lighter shadows and less on each screen.
- Four button styles: main action, second choice, low-key and remove.
- Meals: tap any meal to add or edit it. After saving, the next empty meal is one tap away. A saved meal can be deleted.
- Home shows today's calories, prayers and tasks at a glance, plus all six tools.
- Hub home with today's summary and a tools grid; tabs হোম · খাবার · প্রোফাইল.
- Food tool: pick home-cooked dishes, get suggested portions, see how your plate compares to the suggestion (more, less or close), and log meals.
- Banglish search ("misti kumra" finds মিষ্টি কুমড়া).
- BMI calculator with WHO Asian cut-offs and the normal weight range for your height.
- Three-step setup, profile, history, favourites and food detail screens.
- On-device SQLite storage for profile, meals, favourites and recent foods.
- Backup export and import as a JSON file on the phone, validated before import.
- About page.
- Bundled Hind Siliguri font, Reanimated motion (respects reduce-motion), and a friendly error screen.
